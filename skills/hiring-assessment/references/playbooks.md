# Interview playbooks

## Selection

Use the playbook the user identifies or the one clearly applicable to the role. State the choice. Read its source status before treating it as adopted policy.

- [AI engineering pilot](ai-engineering-pilot.md): Gateway, Governance, Evals and Insights; Junior, Mid, Senior and Principal engineering assessment. Includes the associated data-engineering scenario. This is a pilot proposal, not a department-wide policy. Director and other disciplines need an appropriate role brief and interview structure.

An explicit current user instruction takes precedence over a bundled snapshot. Flag material contradictions between supplied documents rather than quietly merging them. Do not use the later Senior CV-screening discussion to replace the full pilot loop.

For a new discipline or playbook, start from its job requirements and agreed process. Add a bundled reference only when there is reusable guidance to preserve; candidate CVs do not belong here.

## How sources are located

The packaged references are available relative to this SKILL.md installation and need no access to the author's computer. Original deck names and hashes are recorded in the AI engineering reference for traceability. No shared online source location has been configured.

For a refresh, accept the revised file or accessible link from the user. If an exact source location has already been configured and remains accessible, read it directly. Ask for a new location only if needed. Never imply that a filename in the source register grants access to that file or to a previous chat.
